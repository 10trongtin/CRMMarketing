# Marketing CRM — Frontend (Flutter)

Flutter app cho Marketing CRM. Kết nối backend REST API tại `http://<IP-máy>:3000/api`.

Cấu hình địa chỉ backend: `lib/utils/constants.dart` → `AppConfig.apiHost` / `AppConfig.apiPort`.

```bash
flutter pub get
flutter run
```

Tài liệu chi tiết: `docs/README.md`. Cách chạy backend: xem `README.md` ở thư mục root của repo.
